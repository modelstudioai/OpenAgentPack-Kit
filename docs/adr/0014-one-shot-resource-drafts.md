# ADR-0014：创建 Agent 使用一次性资源发布批次

状态：已接受（2026-11-02）。

存储与发布入口由 ADR-0017 调整为新批次使用数据库 YAML；本文件的目录实现仅服务旧批次兼容。
一次性关闭、所有权、成功证明与禁止跨批次复用等生命周期规则继续生效。

## 背景

创建 Agent 向导需要声明并发布新资源，成功后只保留远端引用，不长期维护对应 SDK 源码。
普通项目的 config、state、remote 是持续管理合同：仅删除 config 会在下一次计划产生远端删除，
仅删除 state 则可能重复创建。向导不能继续复用同一个持续管理项目并逐次删减已发布声明。

## 决策

- 向导使用管理员独立的临时 SDK 目录批次，同批 Agent 与运行资源、上传 Skill 一同发布。
  创建动作才初始化，读取不创建。每位管理员最多一个未完成批次，同页内失败后保留同一批。
- 后端只接受已登记批次标识，在受控数据目录定位目录；资源操作复用现有 project service。
  不复制普通项目的资源或 state。官方 MCP 仅复用可公开名称；已发布 Skill 使用云端版本引用。
- Build、Plan、确认令牌及 SDK 发布流程不变。只有本批完整发布成功才关闭批次。
  首先将 ID 与可用版本写入持久成功凭证和 SQLite 回执，然后删除本批源码、YAML、SDK state
  与源码版本库。成功凭证位于批次目录外，不含配置、资源正文、凭据或漂移账本。
- 回执仅用于本地选择转远端引用及清理恢复，不作为后续 SDK state。关闭批次禁止再次修改、
  Build 或发布；下一次创建分配新批次与空 state，仅管理新内容。清理不调用远端删除。
- 有已保存未发布资源时，离开前经 AlertDialog 二次确认；取消保留，确认后自动放弃未发生远端发布的
  本地批次，清理目录、暂存与批次记录，不调用 Provider。空批次、纯远端选择和已发布批次不提示；
  未绑定 Agent 的上传 Skill 也计入未发布内容。刷新/关闭使用浏览器原生离页确认。
  自动清理由用户明确授权，资源或保存弹窗关闭不触发。新页面先处理上次未送达的
  放弃请求，不能把普通未发布内容当作长期草稿恢复；多标签页互斥保护当前使用者，迟到创建也清理。
- 浏览器 Web Lock 只保护同源页面，自动清理另需创建时登记的随机清理凭证。浏览器按后端与管理员身份
  保存凭证，服务端只存哈希；跨浏览器、隐私窗口、不同来源或凭证遗失时拒绝自动接管，不以超时抢占。
  旧无凭证 API 批次仅保留旧 API 显式处理兼容，不允许新向导自动接管。
- 已开始远端执行的失败保留整个现场。部分 state 不等于发布成功；未知结果和进程中断不能自动重发。
  有成功凭证后数据库或清理失败可只重试 finalize，不重复创建资源。
- 回执持久化后释放批次服务、旧计划与上传暂存；关闭后的迟到上传同样释放。读取已关闭绑定或重复 finalize
  直接使用回执，不重建已删除的 SDK 项目或服务缓存。
- 没有未完成批次且只选择远端资源时直接保存模版；正常项目工作台继续保留源码和 state。
- 新建密钥库可附带密钥，明文值仅保留在服务端进程内存，声明使用随机 SDK 环境变量引用。
  本批目录清理成功后释放变量，失败保留；重启后未发布密钥需重新添加，不将值持久化以支持恢复。
  普通项目不支持此临时输入，仍可创建空库；未知发布结果继续遵循原有恢复边界，不自动重发。

## 理由

让 SDK 的持续管理边界与一次性创建边界明确分离，可以在不改写 SDK state 的前提下清理源码，
同时确保未来计划不包含已关闭批次，避免旧资源误删、重复创建或历史声明影响新发布。

## 后果

成功后的资源由远端目录及模版引用继续使用，不再能从已清理批次恢复源码或通过它更新、销毁。
模版历史仍保存引用与展示配置。页面内普通未发布内容临时占用磁盘，退出后放弃；可能已远端执行的失败批次保留以便恢复，结果不明必须核对后处理，
不能靠删除 state 或重建批次自动解决。普通项目已有源码不会被本变更自动清理或迁移。

## 备选方案

- 在共享项目发布后只删除声明：后续计划可能删除旧远端资源。
- 只删除共享项目 state：后续计划可能把已存在资源再次创建。
- 长期保留所有源码和 state：不符合用户要求，且向导新资源发布会带入历史管理范围。
