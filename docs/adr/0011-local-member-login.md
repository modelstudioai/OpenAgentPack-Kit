# ADR-0011：默认成员登录与可撤销身份

## 背景

管理员已能创建本地成员。用户明确要求体验页必须登录，以成员维度管理会话和用量，暂不接
SSO。本决策扩展 ADR-0010 的创建阶段，并保留 Provider 作为事件正文的唯一事实权威。

## 决策

1. 默认 `KIT_AUTH_MODE=member`，体验页在认证前不挂载业务页面，数据面在服务端强制认证。
   显式 `anonymous` 保留演示 / 旧集成兼容；无效 Bearer 不降级匿名。可选可信 JWT 继续可用，
   但 `member_` 命名空间只接受本地成员令牌。
2. 使用已创建账号的用户名和密码登录，签发随机 32 字节不透明 Bearer，固定 8 小时有效。
   SQLite 仅保存 SHA-256 令牌哈希、member_id 和时间，不保存令牌明文。独立登录可分别撤销。
   密码仍使用服务端 scrypt 验证；错误账号与密码统一错误，并限制频率及并发派生。
3. 本地成员 subjectId 固定为 member_id。会话、配额、用量和上传文件沿用此主键过滤；
   不自动迁移匿名数据。下载 Artifact 时查询本人会话的 Provider 历史，不另存事件正文。
   旧库升级只从唯一 subject 的历史挂载索引恢复文件归属，保留原身份且不覆盖已有上传记录；
   跨身份歧义与无索引证据不授予权限。此兼容迁移不合并匿名身份与成员账号。
4. 浏览器按完整 apiBaseUrl（含路径前缀）隔离 sessionStorage，仅保存令牌和到期时间。
   刷新先验证 me；跨域 HTTP、上传、下载和 SSE 统一 Bearer，不依赖第三方 cookie。
5. core 认证 Controller 为每次登录持有独立、固定令牌的 Client；退出 / 过期 / 401 取消
   旧请求，React 重建业务页面，清空旧成员的消息、草稿、附件和用量。网络失败不回落匿名；
   退出撤销失败允许重试。服务端同步关闭已撤销 / 到期令牌的 SSE，不打断 Agent 执行。

## 理由

服务端存令牌哈希可以立即撤销，固定身份的 Client 可以阻止旧异步回调借用新账号令牌。
Bearer 适用于独立域名和桌面 / 移动壳；API 地址隔离避免把一个服务的令牌发给另一个服务。
稳定成员 ID 复用现有归属与 Credits 合同，不将账号体系混入 SDK 或 ChatProvider 事件模型。

## 后果

- 新部署默认需要管理员先创建成员；旧匿名演示须显式设置模式。旧匿名历史保留但不合并。
- sessionStorage 在标签页内支持刷新；关闭页面不会立即撤销服务端令牌，到期自动失效。
  部署应使用 HTTPS，并保护数据库及页面脚本；令牌不进入 URL、日志或公开文档。
- 密码重置、停用、全设备撤销、SSO 与新的成员分析界面仍需独立实现。
- 生成模板复用 core / React 的认证状态机，只复制 UI 与浏览器存储适配。

## 备选方案

- 只做前端登录闸门：无法保护直接访问 API，不满足成员归属要求。
- 无撤销能力的长期 JWT：不能立即结束旧登录，未采用为本地密码登录方案。
- 跨站 cookie：独立域名和 WebView 环境兼容成本更高，保留为显式匿名模式用途。
