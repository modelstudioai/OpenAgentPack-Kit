Kit 提供管理端和体验页：管理员配置智能体、准备运行资源并上架；成员登录后选择智能体，
进行对话、处理工具审批、查看文件和个人用量。

本页按实际使用场景介绍功能。首次运行见[快速开始](/docs/quickstart)，完整操作步骤见
[本地跑通完整 Demo](/docs/local-demo)。

## 智能体配置、预览调试与上下架

管理端通过「创建智能体」和「智能体管理」维护模版，创建与编辑采用「选择配置 → 预览调试」流程。

- **配置智能体**：导入已有智能体的具体版本，或填写模型、系统提示词、工具、MCP 和技能等配置。
  未修改的远端配置可以直接复用；新增或修改资源后，先审阅发布计划并显式确认，再继续预览。
- **预览调试**：上架前即可发送消息、查看执行过程和文件结果。保存后可从详情继续调试，
  并查看已保存的模版配置版本。管理员调试与成员会话、成员用量分别管理。
- **上架与下架**：上架后成员可在广场发现并使用智能体；下架后停止提供新的体验入口，
  已有成员会话和远端资源保留。上下架前均需审阅提示并确认。

发布使新建或修改的资源在百炼生效，上架决定体验页是否提供入口。只复用已有远端配置时，
无需为创建模版额外发布一份资源。

## 成员对话与会话管理

成员使用用户名和密码登录体验页，从广场按分类、搜索或最近使用选择智能体，开始流式对话。

- **查看回复与执行过程**：消息逐步更新，支持思考内容、工具调用和文件结果；执行中可停止。
- **恢复与切换会话**：按智能体分组或从全局「最近」打开历史，支持会话重命名、归档和删除。
  断线后自动恢复订阅；恢复连接不会自动重发消息。
- **删除前确认**：先展示影响并确认；成员会话在执行结束、用量快照保存成功后才删除，
  失败时保留会话供重试。已保存的累计用量继续保留。

桌面和 H5 使用同一套对话流程。操作示例见[成员对话](/docs/local-demo/#从广场完成第一轮对话)，
界面组合见 [Chat 与 Sender](/docs/components/chat)。

## 工具审批与子 Agent

需要人工决定的工具调用会在消息流中展示审批卡，成员可以查看工具名称与实际参数，
逐项选择「允许」或「拒绝」。同批工具分别处理，执行结果继续在对话中更新。
拒绝一个工具与停止整个执行是两个独立操作。

多 Agent 协作时，主消息流内展示子 Agent 卡片，可展开查看任务和执行记录；
右侧资源面板也提供子 Agent 派发记录入口。成员通过主会话发送消息和停止执行。

交互说明见[工具审批](/docs/components/feedback/tool-approval)与
[子 Agent 分区](/docs/components/general/sub-agent-panel)。

## 文件、技能与运行资源

| 能力 | 使用方式 |
| --- | --- |
| 输入附件 | 在新会话发送前上传，随创建会话挂载；已有会话需要新文件时，使用「新建会话并挂载」 |
| 文件结果 | 查看智能体交付的文件，按文件类型预览或下载 |
| 技能选择 | 在输入框用 `/` 选择当前智能体已绑定的技能，作为技能 chip 随消息提交 |
| 运行资源 | 管理员为模版选择或配置环境、预挂载文件、记忆库与密钥库，供后续新建会话使用 |

技能选择表达本轮意图，实际是否执行以及执行结果以智能体返回为准。记忆库可按挂载权限跨会话读写，
密钥库凭据由服务端和 Provider 管理。具体演示见[附件、审批与文件](/docs/local-demo/#附件工具审批与文件下载)。

## 成员、用量与限额

管理员在「成员管理」创建本地成员账号并分配用户名和初始密码，查看成员资料和会话用量。
成员的会话、文件和用量分别隔离；成员管理不再提供用户组界面，已有分组数据与控制面接口保留。

成员在「我的用量」查看已用、剩余和重置时间。管理员在「用量」查看成员与智能体统计，
设置成员默认限额，或针对成员和智能体单独设置 Token、执行时长限额。
达到任一启用的限额后，后续发送会被拦截；已经运行的一轮可能继续消耗。

累计会话统计与当前周期的限额计量分别展示。缺失指标会显示待获取或部分统计，
采集结果不代表最终账单。操作示例见[成员用量](/docs/local-demo/#查看管理员-session-用量)。

需要搭建自己的页面时，参阅[组件总览](/docs/components)与 [SDK 数据接入](/docs/sdk)；
服务端接入和身份、发布流程见[接口总览](/docs/server-api)。
