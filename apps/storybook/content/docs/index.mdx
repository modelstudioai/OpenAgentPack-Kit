OpenAgentPack Kit 是一套搭建 **百炼 Managed Agent 体验页与管理端** 的全栈套件。
管理员在管理端配置智能体模版、准备运行资源、预览调试并上架；成员登录体验页后，
从广场选择已上架的智能体进行对话、处理工具审批、查看文件产物与个人用量。

Kit 包含可自托管的 Node server、可独立接入的会话运行时与 React hooks、copy-in UI
组件，以及项目脚手架。文档组织参考 [ai-sdk.dev](https://ai-sdk.dev)，事件契约直接复用
`@openagentpack/sdk` 的 `SessionEvent`；Kit 负责连接、状态编排和界面展示，不另造一套事件模型。

## 可以怎样使用

- **运行完整应用**：使用仓库内的体验页、管理端和 server，按[快速开始](/docs/quickstart)
  启动本地 Mock 服务。模版创建、成员对话、扩展能力与真实 Cloud 模式见[本地跑通完整 Demo](/docs/local-demo)。
- **搭建自己的页面**：复用 React hooks 和[组件总览](/docs/components)中的组件，也可通过
  `pnpm kit:add <component>` 将组件及依赖源码复制到项目中修改。
- **接入已有百炼后端**：按 [SDK 与 Kit 数据接入](/docs/sdk) 提供 ChatProvider，
  接入已转换事件或百炼原始 SSE；消息、输入、审批等组件沿用同一套契约。

会话运行时按 **Stream → Request → Provider → Chat** 分层，可按需使用流解析、HTTP 请求、
后端适配和会话编排。数据能力可以独立于 React 和 UI 组件使用，当前并不提供通用的多服务商插件体系。

## 当前实现的能力

| 范围 | 已实现能力 |
| --- | --- |
| 体验页 | 成员登录、已上架智能体广场、按智能体分组与全局最近会话、会话重命名/归档/删除、桌面与 H5 导航 |
| 对话 | 流式消息、历史与实时归并、断线续传、停止执行、思考与工具过程、人工工具审批、子 Agent 流内卡片与历史查询 |
| 文件与技能 | 输入附件上传与挂载、产物预览/下载、当前 Agent 已绑定技能的 `/` 选择与内联 chip、技能意图随消息提交 |
| 管理端 | 智能体模版配置、导入已有 Agent、运行资源配置、预览调试、版本管理、上架与下架；不再提供独立上架目录页面 |
| 成员与用量 | 成员管理、每日/月度 Token 与月度执行时长限额、个人用量、管理端用量与智能体操作日志 |
| 开发支持 | 可交互组件预览、OpenAPI 接口参考、三个英文 coding agent Skill、Skill 效果评测工具 |

模版创建与编辑采用「选择配置 → 预览调试」流程。未修改的远端 Agent 可以直接复用；
新增或修改的资源保存到隔离的发布批次，经过 Build、Plan 和显式确认后发布，再保存模版。
上下架在模版管理中完成，底层 Catalog 合同继续服务体验页。

技能选择表达用户意图，不表示 Provider 已成功执行技能；执行结果以实际事件为准。

## 包与应用

| 层 | 包 | 职责 |
| --- | --- | --- |
| 契约 | `@openagentpack/kit-sdk/protocol` | SDK 子入口：事件契约、SSE 帧、错误模型与共享 API schema |
| SDK | `@openagentpack/kit-sdk` | 数据处理：Stream / Request / Provider / Chat、Controller、消息快照与线程/产物归并、KitClient；React hooks 位于 `/chat/hooks`、`/sessions/hooks` 等功能子入口 |
| UI 组件 | `@openagentpack/kit-chat-ui` | copy-in 布局、消息、输入、附件、文件卡、审批与辅助组件；共享 Tailwind v4 与主题 token |
| 服务端 | `@openagentpack/kit-server` | Hono 应用工厂，提供数据面 `/api/kit/*`、控制面 `/api/admin/*` 及成员登录服务 |
| 仓库脚本 | 根 `scripts/kit/` | `pnpm kit:create`、`pnpm kit:add`、`pnpm catalog:list` |
| 开发指南 | 根 `scripts/skills/` | 组件组合、会话交互与后端接入的英文 Skill 源、生成参考和可编译示例 |
| 评测 | `@openagentpack/kit-eval` | Skill 触发/质量评测、远端运行与报告 |

`apps/web` 是体验页，`apps/console` 是管理端，`apps/storybook` 是本站。
体验页支持通过 `window.__OPENAGENTPACK_KIT_BRIDGE__` 注入文件、剪贴板和宿主配置等能力；
页面侧适配留在应用本地，不进入 SDK。

UI 栈按用途区分：管理端的表单、表格等使用 antd v6；体验页与所有端的对话链路使用
`kit-chat-ui`，不在这些区域引入 antd。组件预览直接使用 workspace 中的真实组件。

## 接入边界

1. **Provider 凭据保留在服务端**：浏览器不接收 `BAILIAN_API_KEY` 或 vault 密钥值。
2. **高风险操作先展示计划再确认**：apply、publish、上下架和会话删除等沿用对应的计划与确认令牌流程，无 `--yes` 旁路。
3. **事件与消息以 Provider 为事实源**：本地数据库保存目录、身份和运营索引，不保存事件正文。
4. **支持前后端分离**：默认从 `/api/config` 读取 `apiBaseUrl`，宿主可显式注入；不假设同源。

接入与协议说明见 [SDK 数据接入](/docs/sdk)、[接口总览](/docs/server-api)与仓库权威文档。

## 交付与验证状态

- 核心套件、文档站、脚手架与静态部署产物已可用。Kit 包仍标记为 `private`；
  本站示例面向 workspace 与源码集成，不表示已正式发布 npm 包。
- Mock、组件预览、浏览器回归与真实 Cloud 验证分别执行，某次本地测试通过不代表所有能力都已完成 Cloud 联调。
  具体范围以仓库测试套件与 CI 结果为准。
