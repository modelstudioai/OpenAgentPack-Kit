`@openagentpack/kit-chat-ui` 是 **copy-in registry** 形态（ADR-0005）：组件源码可以整份复制进你的项目自由修改，
样式只用 Tailwind 工具类 + `theme.css` 冻结 token。本站的预览渲染的是**真实组件**（文档站直接依赖 workspace 包），
预览默认显式启用 `workspace` 主题与对应布局变体；复制时保持相同主题、props 与父容器高度即可复现。
手机预览在独立 iframe 视口内运行，用于实际触发移动断点、抽屉和窄屏内容布局。

让 coding agent 帮助选择与组合组件时，可使用英文
[kit-components Skill](/docs/skill/kit-components)。其索引覆盖全部公开组件、子组件与
兼容别名，并同步源码 API 与经过类型检查的组合示例。

```bash
pnpm kit:add message       # Message / MessageList 及富内容组件
pnpm kit:add session-list  # 独立会话列表
pnpm kit:add session-sidebar # 会话目录区（分组 + 最近 + 搜索）
pnpm kit:add agent-header  # Agent 页头
pnpm kit:add prompts       # Prompts 提示集
pnpm kit:add sender        # Sender 输入框
pnpm kit:add attachments   # Attachments 附件
pnpm kit:add suggestion    # Suggestion 快捷指令
pnpm kit:add actions       # Actions 操作列表、复制与反馈
pnpm kit:add file-card     # FileCard 文件展示与下载入口
pnpm kit:add code-highlighter # CodeHighlighter 代码高亮
pnpm kit:add mermaid       # Mermaid 图表与源码视图
pnpm kit:add chat          # Chat 及其依赖（sender / message / markdown）
pnpm kit:add chrome        # 页头、状态与确认弹窗等辅助组件
pnpm kit:add layout        # 整页布局、移动抽屉与页头插槽
pnpm kit:add plaza         # 广场卡片、分类与用量展示
```

## 源码目录

每个独立组件都有自己的目录与中文 `README.md`，入口为
`packages/chat-ui/src/components/<component>/index.tsx`；执行过程组件位于
`components/process/<component>/`。README 说明职责、主要参数、组合关系和文档入口，
已有单测随组件存放，跨组件回归放在包的 `tests/` 中。

`Sender.Header`、`Actions.Copy`、`Attachments.FileCard` 等复合子组件随主组件维护。
`chrome`、`plaza`、`states`、`tool-approval` 保留为重导出入口，原 copy-in 命令继续可用；
也可以单独复制 `confirm-dialog`、`plaza-card`、`meter-bar`、`tool-approval-card` 等组件。
复制后的代码同样保留目录层级；包方式接入仍从 `@openagentpack/kit-chat-ui` 导入。

从旧 copy-in 项目升级时，需要同步更新业务导入：原 `src/components/kit/message.tsx` 中的
`Message` 对应新入口 `src/components/kit/message/index.tsx`，`MessageList` 对应
`src/components/kit/message-list/index.tsx`。`kit:add` 不会删除旧文件或自动合并自定义改动，
请先合并改动并更新导入，再清理旧文件。

## 主题

引入 `@openagentpack/kit-chat-ui/theme.css`，用 `data-kit-theme="dark"` 切暗色。

员工端在根节点显式设置 `data-kit-appearance="workspace"`，启用暖灰视觉基础；与暗色属性
组合时切换到中性深灰。本站组件预览显式选择同一主题；未设置此属性的调用方仍保留原有色板。
主题属性控制色板，`variant="workspace"` 控制组件布局，两者分别设置；组件的默认 `variant` 仍为 `default`。

| 用途 | Token / 员工端表现 |
| --- | --- |
| 页面与侧栏 | `--kit-bg` 为浅暖白，`--kit-bg-subtle` 为暖灰 |
| 卡片、表单与弹层 | `--kit-surface` 提供独立实色表面，`--kit-border-subtle` 弱化区域分隔 |
| 选中与焦点 | `--kit-nav-active` 为中性选中背景，`--kit-focus` 用于键盘轮廓与输入框聚焦 |
| 文字层级 | `--kit-text-meta/caption/label/base/body/heading/title/display`，员工端辅助文字至少 12px，页面标题 20px |
| 正文与代码 | `--kit-text-prose-title/heading/subheading` 定义正文前三层标题；`--kit-code-keyword/string/number` 提供独立亮暗高亮配色 |
| 圆角与阴影 | 控件 10px、卡片 16px；图标与热力图使用独立圆角 token，阴影保持轻量 |
| 输入卡片 | `--kit-radius-composer` 为 24px；`--kit-composer-pane-max-height` 为 160px，编辑区和附件区还会按可视视口高度进一步限制 |
| 状态与遮罩 | danger / success / warning 保留语义色；`--kit-overlay` 统一模态遮罩 |
| 动效 | `--kit-duration-fast/base` + `--kit-ease-out` 驱动 `--kit-animate-*` 入场/弹层过渡与 `.kit-collapse` details 高度过渡；`prefers-reduced-motion` 下自动降级为无动画 |

字体尺寸类使用 `text-[length:var(--kit-text-body)]` 等显式长度提示，避免与文字颜色混淆。
员工端主题在 HTML 根节点启用，因此移动抽屉与 Portal 弹窗也能继承同一组 token。
token 是冻结的：业务代码不得新增颜色/间距/圆角/阴影常量（`packages/chat-ui/AGENTS.md` 不变量 2）。

## 新组件的门槛

**至少一个真实调用方**（`apps/web`、`apps/console` 或 templates）才能进 chat-ui——
只为准需求预建组件库是过度设计。缺 Primitive 时按 Radix + Tailwind v4 + CVA 自研并记录原因。
